## assistant

数控车床就像一台聪明的“旋转切削机”，它有三个关键部分：主轴、进给系统和伺服系统。我们可以这样理解它们的分工：

1. **主轴**：它是带动工件旋转的“动力心脏”。在数控车床上，主轴夹住工件并让它高速旋转，这样刀具才能切削出圆形表面。例如，在攻丝循环（G84）中，主轴正转带动丝锥攻入孔内，反转则退出，主轴每转一圈，进给轴就移动一个螺距。如果没有主轴旋转，车床就无法完成车削工作。

2. **进给系统**：它控制刀具的移动路径。进给系统决定刀具在纵向（Z轴）和横向（X轴）上移动的距离和速度，从而完成外圆、端面、螺纹等加工。在手动操作或自动编程中，进给轴按指令精确运动，比如“手摇进给”时，操作者通过手轮让刀具微量移动。攻丝时，进给轴必须与主轴同步，确保刀具每转一圈移动一个导程，这就是进给系统的作用。

3. **伺服系统**：它是执行“大脑”指令的“肌肉”。伺服系统接收数控系统发出的指令，驱动主轴电机和进给电机转动。如果主轴是伺服主轴，它就像伺服电机一样工作在位置控制模式下，实现与进给轴的插补运动（如同步攻丝）。进给伺服则负责驱动各轴精准定位。当按下急停按钮时，伺服驱动电源被切断，主轴和进给立即停止，这体现了伺服系统对运动的直接控制。

简单来说，主轴负责“转”，进给系统负责“走”，伺服系统负责“准”。三者配合，数控车床才能加工出高精度零件。

需要注意的是，资料中未直接给出这三个系统的明确定义，以上解释是基于操作说明书中的相关描述（如急停时主轴和进给的停止、攻丝时主轴与进给同步）进行的合理归纳。
