# 知链岗位学习进度评价模型 v2

模型标识：`cnc-job-readiness-v2`

## 1. 三类数值必须分开

- **能力暂估**：包含证据不足维度的保守能力估计，用于推荐下一步训练；
- **已验证能力贡献**：只有达到评级门槛的维度才按固定岗位权重计入；
- **达标条件完成度**：当前 L1/L2/L3 阶段通过了多少硬门槛，不是考试分数。

前端不得把三者都称为“综合能力”。未评估、证据不足和正式低分也必须分别显示。

## 2. 固定八维权重

安全 15%、基础识图 12%、工艺规划 14%、数控编程 16%、操作加工 18%、质量检测 10%、维护诊断 8%、先进制造 7%。Memory 和学习进度使用同一权重。

## 3. 理论与实操门槛

阶段判定只使用已达到评级条件的子分。未评估维度不能从平均值中静默消失，纸面 Quiz 也不能代替实操。

### L1 规范上机

- 安全知识、理论与工艺、已审核实操能力均不低于 60；
- 至少 3 个可评级理论维度、1 个可评级实操维度、共 5 个可评级维度；
- 至少 24 条独立有效证据和 3 条已审核实操证据。

### L2 独立加工

- 三类能力均不低于 70；
- 至少 4 个理论、2 个实操、共 7 个可评级维度；
- 至少 56 条独立有效证据和 8 条已审核实操证据。

### L3 岗位综合

- 三类能力均不低于 80，先进制造知识不低于 70；
- 8 个维度全部达到评级条件，其中至少 3 个维度具有实操评级；
- 至少 96 条独立有效证据、16 条已审核实操证据和 1 条有效外部考核。

安全、实操与外部考核均为不可补偿门槛。岗位胜任还要求课程完成度、综合置信度与重大安全缺口状态满足要求。

## 4. 证据链

界面以“原始事件 → 结构化评价证据 → 派生能力与岗位结论”展示，不再把它与 DeepTutor 的 L1/L2/L3 Memory 层级或知链岗位 L1/L2/L3 混为一谈。

原始轨迹只证明活动发生。正式评价证据必须带题目或任务、知识点、能力维度、得分、来源、审核状态和时间。岗位结论始终可追溯到这些证据。

## 5. 系统联动

- Quiz：保存完整作答，但重复题和同知识点刷题受到贡献上限；
- 主观题：低置信 AI 评分进入待复核，不直接改变正式评级；
- 实操或外部考核：审核通过后才能进入岗位门槛；
- RAG：提高证据可追溯性和置信度，但不会直接提高正确率；
- Memory：保存原始证据和模型版本，分数由证据重新计算；
- 中央调度器：接收学习进度快照用于个性化，不得直接覆盖客观能力分。

本模型是知链内部学习诊断规则，不等同于国家职业资格、学校实训成绩或企业上岗认证。
