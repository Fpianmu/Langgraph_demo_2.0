# 知链 CNC 能力评分模型 v2

模型标识：`cnc-capability-v2`

## 1. 评价对象与边界

能力评价只使用可审计的 Quiz、实操和外部考核结果。聊天次数、资料浏览、用户自述水平以及 Agent 的主观建议不能直接增加能力分。该模型用于学习诊断，不等同于职业资格或企业上岗认证。

八个维度为：安全规范、专业基础与识图、工艺分析与加工规划、数控编程与程序校验、机床操作与加工实施、质量检测与误差控制、设备维护与故障处理、先进加工与智能制造。

固定岗位权重为 `15 / 12 / 14 / 16 / 18 / 10 / 8 / 7`。Memory 与学习进度共用这一套权重，不再随用户自填的初级、中级、高级改变。

## 2. 证据结构

每条证据至少保存：

- `attemptId`、`attemptNumber`、`itemRevision`；
- 能力维度、维度来源、知识点与规范化知识点 ID；
- `earned / possible`、难度、题型、时间；
- `sourceType`（Quiz、实操、外部考核）与审核状态；
- 题目级 `source_refs`、`rag_chunk_ids` 和是否真正逐题落地；
- 主观题评分方法、量规版本、语义得分、关键点评分与评分器置信度；
- 可选 `lectureId / chapterId / objectiveIds`，用于讲义目标的精确评价。

整批检索得到的来源只标记为会话级来源，不能冒充每道题都被具体 RAG 切片支撑。

## 3. 有效证据

原始记录完整保留，但正式评分只使用有效证据：

1. 同一道题的不同重复尝试，默认只计第一次独立暴露；
2. 同一尝试中，同一能力维度、同一知识点最多贡献一次；
3. Quiz 客观题可自动核验；低置信 AI 主观题进入“待复核”，暂不改变正式评级；
4. 实操和外部考核只有审核通过后才计入；
5. 无效分值、被拒绝记录不参与评分，但保留审计痕迹。

## 4. 观察表现、能力估计与置信度

单条表现率 `rᵢ = earnedᵢ / possibleᵢ`。

```text
证据权重 wᵢ = 难度权重 × 180 天时间衰减 × 来源可靠度
              × 维度归类可靠度 × 主观评分器可靠度

观察表现 = Σ(rᵢ × wᵢ) / Σwᵢ
```

难度权重为基础 `1.0`、中等 `1.2`、进阶 `1.5`。实操和外部考核的来源权重高于纸面 Quiz；关键词推断或兜底归类的权重低于题目明确声明的维度。

小样本采用均值 50%、强度 4 的中性先验收缩：

```text
能力估计 = (Σ(rᵢ × wᵢ) + 0.5 × 4) / (Σwᵢ + 4)
```

因此，一道题全对仍可显示“观察表现 100%”，但能力暂估不会直接变成 100，更不会显示“熟练”。

置信度由有效证据量、知识点覆盖、独立尝试次数以及题目级 RAG 落地程度共同构成：

```text
置信度 = 45% × 证据量完成度
        + 25% × 知识点覆盖度
        + 20% × 独立尝试覆盖度
        + 10% × 题目级来源覆盖度
```

最低评级条件为：有效证据不少于 4 条、至少 3 个知识点、至少 2 次独立尝试、置信度不低于 40%。未达到时仅显示“证据不足”和暂估值。

正式掌握等级仅在达到评级条件后显示：`<50 需巩固`、`50–64 入门`、`65–84 基本掌握`、`≥85 熟练`。

## 5. 理论与实操分离

每个维度同时保留 `knowledgeScore` 与 `practiceScore`。Quiz 只能更新知识子分；实操或经审核的外部考核才能更新实操子分。操作加工、质量检测和维护诊断不能因为纸面题全对而判定为岗位熟练。

## 6. HTTP v2 中的评分数据兼容

第二版任务接口使用 `api_version=v2`。Memory 工作区快照独立使用 `state_version=1`，并保留 `latest_scores: dict[str, float]` 作为生成内容的个性化上下文。内部证据快照通过 `model_version=cnc-capability-v2` 区分。

旧接口需要数字时，尚未达到评级门槛的维度发送 `0`，并额外发送 `{dimension}_provisional`、`{dimension}_assessed` 与 `{dimension}_confidence`。这样 Agent 仍可利用暂估值调整内容，又不会把低样本暂估冒充正式成绩。正式 UI 始终区分“待评估”“证据不足”和“正式低分”。

## 7. 资料依据

评价维度与岗位权重参考 `resource` 中的数控车铣、多轴职业技能等级标准，初/中/高级考核大纲、车工国家职业标准、安全题库、综合实训教材及设备说明书。当前权重属于知链内部评价规则，不宣称为官方证书成绩换算表。
